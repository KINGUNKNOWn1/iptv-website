❌ Critical Issues Requiring Immediate Action

1. Technical SEO Issues Critical

  • Client-Side Rendering (CSR) SPA: Content only visible after JavaScript execution. Empty HTML root div means search engines must render JavaScript. Impact: Delayed indexing, broken social previews, incompatible with Bing/DuckDuckGo.
  • No Security Headers: Missing HSTS, CSP, X-Frame-Options, X-Content-Type-Options. Both security vulnerability and SEO ranking factor.
  • Outdated Sitemap Dates: All URLs show lastmod: 2024-01-08 (20 months old). Reduces crawl budget allocation.
  • Poor Core Web Vitals: Estimated LCP: 3.5-5.0s (Poor) due to Three.js loading on homepage. Estimated CLS: 0.15-0.25 (Needs Improvement).
  • Dynamic Meta Tags Not Discoverable: React Helmet injects meta tags after JS execution. Blog posts show generic homepage metadata to crawlers.

2. Schema & Structured Data Issues Critical

  • Unverified AggregateRating: Claims 2,847 reviews with 4.9 rating but no Review schema exists. Google may flag as manipulative.
  • Dynamic priceValidUntil: Calculates "today + 30 days" on each render, causing inconsistent cached data.
  • Static Breadcrumbs: Same breadcrumb appears on all pages instead of being route-specific.
  • Incomplete Organization Address: Missing street address and postal code (required for local search).
  • Missing Product Seller: All offers lack required seller property.

3. Search Experience (SXO) Issues Critical

  • Page Type Mismatch on /iptv-kopen: SERP expects product page with pricing. Site delivers informational layout with pricing below fold. 90% of competitors show price within first 400px.
  • Missing Trust Signals: No visible payment logos, security badges, or review widgets despite having 4.9/5 rating in schema.
  • Meta Description CTR Gap: Missing price anchors and urgency signals that 8/10 competitors use ("binnen 5 min", "iDEAL betaling").

4. Content Gaps High Priority

  • Missing /blog Index Page: Listed in sitemap (priority 0.7) but not created. Prevents blog content aggregation.
  • Thin "Over Ons" Page: Only 400 words. Needs company story, team info, trust signals (800-1,000 words recommended).
  • Outdated Year References: "Beste IPTV Apps 2024" needs update to 2026. Hurts credibility.
  • Missing Article Schema: None of the 5 blog posts have BlogPosting/Article schema. Reduces blog visibility.
  • No Competitor Comparison Page: High-value opportunity for "iptv vergelijken" searches (1,000+ monthly).
